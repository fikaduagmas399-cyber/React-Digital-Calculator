# React Calculator

A modern, mobile-first responsive arithmetic calculator built with **React** and **Vite**. Developed as part of my frontend web development portfolio.

## Live Demo

[Check out the live application here](#)

## Feature

-Responsive design optimized for Mobile, Tablet, and Desktop screens.
-Supports basic arithmetic operations (+, -, \*, /, %).
-Negative number handling at the start of calculations.
Clean and smooth user interface with a native app-like experience.

## Built With

- **React**
- **Vite**
- **CSS3**

## How to Run Locally

Clone the repository and run the following commands:

```bash
# Install dependencies npm install
# Run the development server npm run dev

```
